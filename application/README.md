# B-Fabric

## Overview

B-Fabric is an information platform for managing research data and processes, with a focus on life sciences. It stores experimental data together with its scientific context and connects that data to analysis tools and workflows. The platform helps ensure reproducibility, transparency, and secure access control across a project's lifecycle.

## Key features

- Project lifecycle management: Track the full life cycle of research projects from application to completion.
- Context-aware data capture: Store experimental data together with metadata and provenance.
- Data provisioning: Provide data to analysis tools and users as needed.
- Reproducible analyses: Capture data-generation pipelines and provenance to support reproducibility.
- Search and discovery: Fast, advanced search across data and metadata.
- Security and access control: Flexible role-based access to data and services.
- Service management: Transparent service ordering, charging, and invoicing.

## Technology stack

- Jakarta EE for the web application
- PostgreSQL for structured data storage
- Hibernate for object-relational mapping
- Apache Lucene for advanced search
- Payara as the application server
