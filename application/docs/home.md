# B-Fabric Documentation

B-Fabric is an information infrastructure for managing experimental data and workflows in life sciences research. It stores experimental data together with its scientific context and integrates that data with analysis tools to support reproducible, traceable research.

## Key features

* Complete project lifecycle management: track projects from application to completion.
* Context-aware data capture and delivery: store experimental data with metadata and provide it to users and tools as needed.
* On-demand data generation: invoke analysis applications directly on relevant datasets.
* High reproducibility: record data-generation pipelines and analysis steps to make results reproducible.
* Transparent data location management: users access data without needing to manage its physical location.
* Powerful search and access controls: searchable data with flexible, role-based access control.
* Service and billing management: manage service orders, charging, and invoicing transparently.

## Platform and components

Key components include:

* Jakarta EE (Web application framework) — https://jakarta.ee/
* PostgreSQL (database server) — https://www.postgresql.org/
* Hibernate (ORM) — https://hibernate.org/
* Apache Lucene (search) — https://lucene.apache.org/
* Payara (application server) — https://www.payara.fish/downloads/#community
