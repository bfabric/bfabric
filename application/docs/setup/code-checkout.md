# B-Fabric Documentation

## Code Checkout

```
git clone https://github.com/bfabric/bfabric.git`
```

The B-Fabric parent project includes these subprojects:

* `application`: source for the B-Fabric Web Application  
* `downloadmanager`: source for the B-Fabric Download Manager

The download manager's JAR is provided inside the Web Application's \`fragments\` folder.
