# B-Fabric Documentation

## GlassFish Server

B-Fabric runs on all GlassFish Servers, which support Java 8. Currently, we use the Payara Server.

* Download Payara Server (Community Edition, Version 5) from https://www.payara.fish/products/downloads/all-downloads/#community.

* Download PostgreSQL Driver Version (currently 42.7.8) from https://jdbc.postgresql.org/download/postgresql-42.7.8.jar and put it into the payara5\glassfish\lib folder.

  The successful completion of this part of the guide is crucial for the system to run.
