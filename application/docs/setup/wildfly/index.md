# B-Fabric Documentation

## Wildfly Server

A step-by-step guide for installing/configuring the http://wildfly.org Wildfly Server, so it can be utilized in B-Fabric system. The successful completion of this part of the guide is crucial for the
system to run.

Only for B-Fabric-Seamless

### Hints and Experiences

The installation guide is done for Wildfly 10.0.10.Final.
