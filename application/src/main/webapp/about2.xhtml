SelectManyCheckbox

Aktuell nicht unterstützt. Nachteile: bietet keine generische Lösung für die Auswahl von zulässigen Kombinationen, Implementierung ist verhältnismässig aufwändig, da Parameter name-value pairs sind -> multi-valued Parameter müssten modelliert und umgesetzt werden:



SelectOneMenu

Aktuell empfohlene Lösung, bei der alle zulässigen Kombinationen von den App-Developern explizit bereitgestellt und entsprechend vom User ausgewählt werden können. Nachteil: explizite Auflistung kann bei einer grossen Menge von Optionen gross werden (2 hoch n mögliche Kombinationen; für n kleiner 7 ist die Auswahl/Präsentation locker zumutbar), Vorteil: einzige Variante, bei der App-Developer die Auflistung kontrolliert und somit unzulässige bzw. unerwünschte Komnination ausschliessen kann:



SelectOneRadio

Statt SelectOneMenu werden die Optionen als SelectOneRadio dargestellt, d.h. mit den Vorteil, dass der App-developer die zulässigen Kombinationen festlegen kann and diese Kombinationen direkt sichtbar sind. Nachteil: bei einer grossen Anzahl von Optionen kann die Darstellung unübersichtlich werden. Diese alternative Darstellungsvariante könnte mit überschaubaren Aufwand aktuell relativ einfach umgesetzt werden:
