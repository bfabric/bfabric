Terms

Choosing the right search terms is the key to finding the information you need.
Start with the obvious – if you're looking for general information on Drosophila, try "Drosophila".
But it's often advisable to use multiple search terms; if you're looking for Drosophila Extracts, you will do better with extracts Drosophila than with either Drosophila or Extract by themselves.

A query is broken up into terms and operators. There are two types of terms: Single Terms and Phrases.

  • A Single Term is a single word such as "test" or "hello".
  • A Phrase is a group of words surrounded by double quotes such as "hello dolly".

Multiple terms can be combined together with Boolean operators AND (or +), OR, and NOT (or -) to form a more complex query. Note that these operators have to be written in upper letters.

Hence, omit the symbol - in a search term representing a date. Write 20120529 instead of 2012-05-29.

Capitalization

Searches are case in-sensitive. All letters, regardless of how you type them, will be understood as lower case. For example, searches for drosophila, Drosohpila or even dRoSoPhIla will all return the same results.

Automatic Exclusion of Common Words

A search ignores common words and characters such as "where" and "how", as well as certain single digits and single letters, because they tend to slow down your search without improving the results.

Document Types / Search Fields

The search can be limited by selecting the desired document types. When a document type is selected, the list of available fields is loaded according to the supported fields of the selected document type.

Wildcard Searches

Both single and multiple character wildcard searches are supported within single terms (not within phrase queries).

  • To perform a single character wildcard search use the "?" symbol.
  • To perform a multiple character wildcard search use the "*" symbol.

To get all documents, just enter a single "*" symbol in the search field. But be aware that such a query might take a long time.

Fuzzy Searches

To do a fuzzy search use the tilde, "~", symbol at the end of a Single word Term. For example to search for a term similar in spelling to "roam" use the fuzzy search: "roam~"
This search will find terms like foam and roams.
An additional (optional) parameter can specify the required similarity. The value is between 0 and 1, with a value closer to 1 only terms with a higher similarity will be matched. For example: "roam~0.8"
The default that is used if the parameter is not given is 0.5.

Proximity Searches

Words which are within a specific distance can be found. To do a proximity search use the tilde, "~", symbol at the end of a Phrase. For example to search for a "apache" and "jakarta" within 10 words of each other in a document use the search: "jakarta apache"~10

Range Searches

Range Queries allow one to match documents whose field(s) values are between the lower and upper bound specified by the Range Query. Range Queries can be inclusive or exclusive of the upper and lower bounds. Sorting is done lexicographically.
The query [Aida TO Carmen] will find documents that have values between Aida and Carmen, inclusive.
The query {Aida TO Carmen} will find all documents whose titles are between Aida and Carmen, but not including Aida and Carmen.
Inclusive range queries are denoted by square brackets. Exclusive range queries are denoted by curly brackets.

Lucene runs a fulltext search. However, you may use range queries to simulate less/greater than comparisons of positive numbers under some restrictions.
Write [0 TO 42.8] to express less than or equal 42,8.
Write {61,25 TO 999999999} to simulate a greater than 61,25 comparison, while you assume that there is no number greater than 999999999.
In other words, use a number for the right boundary that is expected to be higher than all values of the given field.

Check out Lucene's Query Parser Syntax web page for more detailed help.
