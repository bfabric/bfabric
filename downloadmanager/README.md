# B-Fabric Download Manager

## Overview

The B-Fabric Download Manager is Java Web Start software to download data from the B-Fabric information platform. It allows downloading single resources as well as entire workunits, orders, or even projects. A requirement for using the B-Fabric Download Manager is a working installation of Java. Java Web Start is needed for opening the provided jnlp file to start the Download Manager.

This B-Fabric Download Manager provides a graphical interface to monitor, pause, resume, and manage multiple downloads efficiently.

## Features

* Download multiple files concurrently
* Pause and resume downloads
* Progress tracking with GUI
* Support for various download statuses
* Integration with B-Fabric authentication
